## ADDED Requirements

### Requirement: A roadmap of all changes

The repository SHALL keep a root `ROADMAP.md`, mostly generated by `mise run openspec:roadmap --write`, that lists every change with its order and dependencies; a new change SHALL get its roadmap fields in the commit that creates it, and `AGENTS.md` SHALL tell a session to run `mise run openspec:roadmap` first; the file SHALL never be deployed to the home directory; the former `TODO.md` SHALL be removed once its content is in `ROADMAP.md`.

#### Scenario: Roadmap is current

- **WHEN** `mise run openspec:roadmap --check` runs at the repository root
- **THEN** it exits 0

#### Scenario: Read-first pointer

- **WHEN** `grep -c 'mise run openspec:roadmap' AGENTS.md` runs
- **THEN** it prints at least 1

#### Scenario: Roadmap is not a target

- **WHEN** `chezmoi managed | grep -c -E '^ROADMAP\.md'` runs
- **THEN** it prints 0

#### Scenario: Frozen change map

- **WHEN** section 6 of `docs/audits/2026-10-30-environment.md` is read
- **THEN** it states that it is a snapshot and points to `ROADMAP.md` for the current order

#### Scenario: Task list retired

- **WHEN** `git ls-files TODO.md` runs
- **THEN** it prints nothing

#### Scenario: Seed keeps the planned order

- **WHEN** the changes of the sequencing table in `ROADMAP.md` are compared, on the commit that creates it, with the planned order of `TODO.md` on the parent commit
- **THEN** the changes common to both appear in the same order
