# AGENTS.md - Tmux Configuration Repository

## Repository Overview
This repository contains tmux configuration files managed via TPM (Tmux Plugin Manager).

## Build/Lint/Test Commands

### Configuration Validation
```bash
# Validate tmux configuration syntax
tmux source-file ~/.config/tmux/tmux.conf

# Check for syntax errors without reloading
tmux source-file -q ~/.config/tmux/tmux.conf
```

### Running Tests
This repository does not contain automated tests. However, you can manually test:
```bash
# Test configuration by reloading tmux
tmux source-file ~/.config/tmux/tmux.conf

# Start a new tmux session with the config
tmux -f ~/.config/tmux/tmux.conf new-session
```

## Code Style Guidelines

### Tmux Configuration Style
- Use `set` shorthand (not `set-option`) for brevity
- Use `setw` shorthand for window options
- Prefer `-g` (global) flag for default settings
- Use `-a` for appending to lists, `-q` for quiet operations

### Formatting
- Indent with 2 spaces for nested configurations
- Group related settings with blank lines between groups
- Keep lines under 80 characters when possible
- Use lowercase for all tmux commands

### Naming Conventions
- Use descriptive variable names with underscores (e.g., `@catppuccin_flavor`)
- Prefix custom variables with `@`
- Use hyphen-separated words for tmux options

### Organization
Order configuration sections:
1. Terminal and color settings
2. Prefix and key bindings
3. Window and pane settings
4. Plugin declarations
5. TPM initialization (must be last)

### Key Binding Conventions
- Use `bind` for new bindings, `bind-key` for explicit mode bindings
- Group bindings by functionality (navigation, splits, copy-mode)
- Use `unbind` before rebinding keys

### Comments
- Use `#` for single-line comments
- Add URLs for external references
- Explain non-obvious configuration choices
- Keep comments concise

### Error Handling
- Use `if-shell` for conditional logic
- Test shell commands with `[ ]` syntax (POSIX compatible)
- Provide fallback values for environment-dependent settings

### Plugin Management
- Pin plugins to specific versions when available (e.g., `#v2.1.3`)
- Group plugin settings with plugin declarations
- Keep TPM initialization line at the very bottom of `tmux.conf`

## File Structure
- `tmux.conf` - Main configuration file
- `tmuxline.conf` - Status bar styling (generated by tmuxline.vim)
- `plugins/` - TPM-managed plugins (do not edit directly)

## Important Notes
- TPM initialization line must be at the bottom of `tmux.conf`
- `if-shell` uses `/bin/sh` - no bash-specific features
- Shell commands in tmux config are evaluated at config load time
- The `tmuxline.conf` file is auto-generated - prefer editing `tmux.conf` instead
